# 句得（哔哩哔哩 / YouTube）

面向高中和大学英语学习者的本地扩展，版本 1.5.0：阅读字幕、收集词句、翻卡自测、打印 Word。全中文界面：字幕、概览、收藏库和学习。保留原有笔记，支持两种视频平台。

## 加载开发版

使用 Chrome 116 或以上版本。在 `chrome://extensions` 开启开发者模式，点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的目录。也可以解压安装包后选择解压目录。不要选择 ZIP 或外层目录，加载后不要移动或删除文件夹。

建议用单独的 Chrome 用户配置测试开发版。原来的日常版及数据保持不变；不同扩展或用户配置不共享存储，需要自己在开发版设置中填写密钥。本扩展存储中已有的 Notes 和 Vocabulary 记录保持原有结构，不按文字长短自动迁移。

修改代码后在扩展管理页重新加载，再刷新视频页面。扩展只使用当前活动的哔哩哔哩或 YouTube 标签页，不借用后台视频。

## 配置密钥

在「设置」填写 DeepSeek 密钥。哔哩哔哩字幕直接从 B 站获取，不需要 Supadata 密钥；使用 YouTube 时才填写 Supadata 密钥。部分 B 站字幕需要先登录。优先选用英文字幕；没有字幕轨时明确提示，不能提取画面内嵌字幕。B 站分 P 分别保存缓存、词句与学习记录。YouTube 的 Supadata 先请求原生字幕；无字幕时，只有点击生成并确认后才请求音频转写。AI 功能沿用 DeepSeek V4 Flash。密钥仅存本地，不要放到聊天、源码或截图里。

官方入口：[Supadata](https://dash.supadata.ai/)、[DeepSeek](https://platform.deepseek.com/api_keys)。服务可能收费，请查看 [Supadata 价格](https://supadata.ai/pricing) 和 [DeepSeek 价格](https://api-docs.deepseek.com/quick_start/pricing)。悬停查词达到 600 毫秒后会调用 AI；相同单词和语境的成功结果在后台内存缓存最多 30 分钟。导出 Word 和翻卡复习不调用 AI。

## 收藏与 Library

- 在 Transcript 英文原文上悬停 600 毫秒，显示音标、语境释义和收藏按钮；点击后才收藏。发音使用本机语音。
- 划选英文字幕后点击「收藏长难句」，支持跨相邻字幕行。先保存原句，再生成中文翻译、句子主干、结构拆解和标签。失败仍保留原句，可在 Library 重试；仍可选择「解释」或「收藏词／短语」。
- 操作范围是 Original 或双语模式中的英文原文，不包括中文字幕和视频画面上的字幕。
- Library 分 Vocabulary、Sentences、Notes。词句支持当前视频／全部、搜索、复习状态筛选、收藏时间升降序和英文 A–Z；当前视频下可按视频出现顺序排列。
- 长难句分别设置语法标签和表达标签，可多选、手动修改、筛选、分组。同一句可出现在多个分组，导出时按 ID 去重。
- 单词和长难句分别上限 500 条，到达上限提示，不自动删除旧收藏。旧单词库里的长句不会被自动重新分类。

## 跟随播放

字幕工具栏提供「回到播放位置」，每次点击读取当前视频时间并定位，暂停时也可用。沉浸模式会自动切换当前台词，交互后可点击「跟上播放」恢复同步。

## 学习任务与复习（1.8.0）

「学习」先显示待开始。范围为当前视频；默认有效时长 20 分钟、单词练习 5 个、句子练习 2 个，词句目标可以设为零。项目尚无片段选择器。顶部固定显示任务状态、累计和剩余时长、练习进度及暂停／继续、结束并总结按钮。

已收集与已练习分开：加入收藏库不会增加练习进度。打开翻卡或查看答案也不算完成；选择「记住了／不熟／没记住」才计入本次练习。同一词句只增加一次目标进度，自评不代表掌握。可以练习当前视频的剩余词句，或复习本次不熟内容。

有效时间为观看、字幕与词句操作、翻卡复习的去重之和。活跃复习优先，其次为有效词句操作，再其次为前台观看。操作和复习在 60 秒无有效交互后停止；普通鼠标移动不算交互。倍速按真实时间计算，后台、窗口失焦、离线、缓冲、拖动及手动暂停不计观看。任务状态与计时原因分开展示，完整说明见「计时规则」。

到达时长目标只提示总结或继续，不强制暂停视频，也不截断后续计时。剩余时间最低为零；只有时长和两类练习目标均达到才显示目标已完成。提前结束展示实际进度和未达标项目。

重新打开学习区、刷新视频、更换视频或浏览器后台服务重启后保留任务并等待手动继续，不补计离开时长。继续时可以绑定当前前台的同一视频，恢复保存的播放位置；不会自动开始播放。结束后也可继续上次学习。减少推荐与评论干扰沿用已有页面控制，退出任务后撤销。

本次总结包含三类时长、练习数／目标数、待复习数量和达标情况；下方显示今日摘要与可点击查看明细的七日柱状图。没有记录时显示引导。学习页和设置均支持导出 Excel（.xlsx） 或确认后清空学习记录。数据仅存本机，保留 90 天；清空不会删除词句收藏、笔记及收藏库自评。旧记录保留既有时长和收藏，不推测历史练习成果。

## 下载 Word

在「收藏库」点击「下载 Word」，选择当前筛选结果或勾选项，可合并单词与长难句。各类沿用适用的筛选和排序，生成前显示数量。

- 学习讲义：单词、音标、中文释义、来源例句；长难句、译文、句子主干、拆解和分类。
- 自测版：中文释义默写英文单词、中文句子翻译为英文，横线作答；英文答案与来源例句另起页附在文末，题号对应。缺失中文题目的条目提示补全后重新导出。

输出真实 `.docx`，A4 纵向、黑白、页码，附来源标题、时间点和链接；未完成解析会明确标记。扩展内置 docx 9.6.1 库，本地生成，不上传文档内容，不加载远程脚本。

## 保留的功能与开发验证

Transcript 搜索仍是字面匹配，支持上一个／下一个；阅读位置按当前视频保存在浏览器会话中，最多 20 个视频，会话结束后清除。Overview 和 Notes 保留。已移除 Ask 及联网搜索，启动时清理旧搜索密钥和提问建议缓存，不修改词句收藏。

运行 `npm ci --ignore-scripts` 安装开发依赖，再运行 `npm test`、`npm run check` 和 `npm run package`。浏览器加载不需要构建；运行文件和固定版本的 Word 库已经包含在目录中。`npm run vendor:docx` 从锁定依赖重新生成库副本。

`npm run test:browser` 使用隔离 Chrome 配置和模拟字幕／AI；首次先运行 `npx playwright install chromium --no-shell`。自动化测试不发付费请求。真实视频和服务账户可用性需要另行验证，AI 释义与句法标签也需要学习者判断。

## 本地转写的内存、磁盘与清理规则

识别英文原声需要临时下载音频（不是整部视频画面）并在本机运行模型，所以识别期间会占用内存和磁盘，并非完全不占资源。

- 正常完成、失败或取消后，清理该任务的临时音频；无需等视频看完。
- 转写进程退出后，操作系统释放其识别内存；浏览器和轻量本地服务仍会占用各自的运行内存。
- 识别模型保留在本机磁盘供下次复用，不会随任务删除，也不会每次重新下载。
- 字幕文本和翻译保留缓存，避免重复识别。扩展字幕缓存有效期为 30 天，按缓存读写规则淘汰；本地服务在启动时清理创建超过 7 天的任务目录，并非每天定时清理。
- 强制终止进程或异常断电可能留下临时文件；不保证异常情况下立即清理。学习记录的 90 天保留规则与字幕缓存分开，清理学习记录不会删除收藏。

加载中的简短提示会说明临时占用与自动清理，任务结束后收起，不持续占用字幕显示空间。

沉浸模式持续将当前播放句的英文对齐字幕区顶部，中文紧随其后；跟随开启时，同一句内的翻译更新或调整高度后，下次播放位置刷新会自动重新对齐。用户手动滚动字幕后停止跟随，点击“回到播放位置”或点击字幕跳转播放后恢复。划选文字期间暂缓移动，取消选区后在未手动滚动的情况下恢复。左右侧栏的手动滚动规则保持原样。

沉浸模式查词时暂停跟随：单词高亮等待查词、词卡打开（含收藏请求中）、划选和解释窗口期间不自动滚动。离开单词并关闭词卡、取消选区后仅在未手动滚动时恢复当前句顶部对齐；收藏成功后仍打开的词卡可继续阅读，关闭后恢复。

沉浸模式仅在播放器报告正在播放时自动置顶当前句；视频暂停后允许自由滚动，继续播放后仅在未手动滚动时恢复跟随。主动点击字幕跳转或“回到播放位置”仍立即对齐。

## 本集闯关学习（1.14.0）

自由学习、原有计时、收藏、翻卡与 Word 导出继续保留。学习页新增可选闯关区：开始前告知出题与判题会使用配置的 DeepSeek API；仅从开始后本标签页在前台播放过的英文字幕出题，优先选用适合的收藏词，再补齐目标 8 道单词和 4 道常用短语题。中文题干填写英文，每类正确率至少 75%（向上取整）通关；素材不足则减少题数并明确告知，不冒充正式四级测评。生成的答案必须出现在所引字幕中，题面不得包含英文。

未匹配预设答案的回答交给 DeepSeek 判断合理同义表达；不确定或服务失败时不计错，保存回答供重试或退出。首次成绩与错题补测分开，补测通过不意味着一次掌握。试卷成功生成后复用，重复点击合并请求；浏览器中断的请求可手动重试，服务端已经发生的费用不能保证退回。生成与判题中的退出/清空会使迟到结果失效。

闯关只限制已加入任务的标签页内的后续视频播放：本集结束、测试中或切到其他视频时暂停并显示测试/退出入口。可以在学习页结束当前观看提前测试，因此它不是完整看完一集的证明。允许退出且记为未通关；不限制关闭插件、换浏览器或新标签页，不能作为防作弊或家长控制。刷新后保留进度并需手动继续；拖动、后台、缓冲、离线和休眠不补记播放片段。

新增独立 ytd_challenges（schemaVersion 1），不改旧学习记录或收藏结构。试卷、答案、自评以外的客观练习结果、观看区间和作答仅存本机，保留 90 天（访问时清理），最多 200 次记录、每任务最多 30 次提交。原有“导出学习记录”包含闯关记录；确认清空会清理两类学习记录，但保留收藏与笔记。仅向 DeepSeek 发送选取的已观看字幕、候选收藏词、题目和待判回答，不发送其他视频或本地密钥。出题抽样最多 240 行，过长字幕提示使用较短单集。

新增 challenge-core/worker/ui/content 模块。写操作串行化，AI 请求在队列外；题目生成、判分用任务 ID 与 revision 防迟到覆盖。新数据接口仅扩展页可调用，内容脚本只能发播放采样、主动退出及打开侧栏；播放采样结合真实发送标签页和活动窗口核对。试卷初次提交前不通过页面消息返回参考答案。浏览器本机数据不提供考试级保密。

自测内容筛选：自动闯关出题和 Word 自测排除明显色情、下流、脏话及相关例句；自动出题另要求模型检查隐喻和语境。合适素材不足时减少题量，不凑题。原字幕和收藏不因此删除。规则与模型筛选不能保证识别所有隐晦表达，课堂使用前仍可复核。


## 家长模式（1.15.0）

原自由学习、收藏和普通闯关保留。家长在学习页选择“家长设置密钥”，抄下仅当次显示的 9 位数字，隐藏后重新输入确认启用。退出模式必须验证密钥；密钥不会再次显示，也没有免密解除入口。忘记密钥时不能通过本功能恢复，请妥善保存。

- 同一浏览器中扩展支持的 Bilibili / YouTube 视频页面遵循家长任务，切换标签页不会直接解除。通过后，下一个未完成视频自动建立任务；已完成的视频可以回看。
- 从启用本集任务后实际观看的英文字幕统计不同收藏项。收集 10 个单词、5 个句子并实际观看至少视频时长的 80% 可完成收集任务，记录不表示已掌握。收藏不足或观看不足则进入测试。未收藏也能从已观看字幕出题。
- 本集结束或尝试进入其他视频时，字幕素材已就绪会自动准备试卷；可以提前选择“结束观看，准备测试”。失败后提供重试，不自动循环调用收费接口。
- 家长试卷为 10 道单词中文提示默写英文（每题 0.5 分）和 5 道完整句子中译英（每题 1 分），满分 10 分，达到 8 分通过。模型优先挑选常用动词、形容词和四级及以上难度语料；这不是正式四级测评。语义相符的自然译法可以判对。
- 题干、答案及来源例句继续规避色情、下流、脏话等。可靠安全素材不足 15 题时不按小卷放行，可回看、补齐英文字幕后重试或请家长解除；不编造台词凑题。
- 未通过先逐项复习错题、自评记住，再重新作答整张试卷。整卷独立计分，首次成绩保留，不用历次正确答案累积凑够 8 分。参考原声回放限于错题对应片段。
- 判题或出题服务失败不会记为答错或自动解锁，可重试或由家长解除。出题和必要判题使用现有已配置 AI 服务，可能产生费用；不新增账号、后台或第三方分析。
- 密钥仅首次设置返回到家长界面，本机保存随机盐与 PBKDF2-SHA-256 校验值（210000 次），不保存明文；5 次错误后等待 60 秒。待确认密钥 10 分钟过期。校验信息不进入学习记录导出，保留到解除；学习记录依旧只存本机、保留 90 天。家长模式开启时，清空学习记录须先解除，不删除收藏。
- 限制范围是扩展支持的此浏览器视频页，不是系统级控制。卸载/禁用扩展、清除扩展数据、使用其他浏览器或应用仍可绕过；本机数据并非防篡改证据，不能据此保证学生专注或掌握。

Word 下载提供“纯讲义版”和“讲义＋测试题版”。后者依次包含完整讲义、另起页的中文出题英文作答测试、另起页的参考答案；测试部分继续筛选课堂适宜内容。

家长模式入口（1.15.5）：仅在学习页右上角常驻显示开关，滚动时仍可见，默认不展示家长设置大卡片；开启与解除在密钥弹窗内完成，开关只反映已确认状态。取消弹窗不解除模式。普通闯关及观看中的家长任务使用轻量状态行，直接提供继续或开始测试操作；不再使用折叠任务框。测试和错题复习需要处理时展示。确认开启可结束现有普通闯关并保留记录。

学习页顶部展示最近 7 天趋势及每日明细；计时规则、学习记录导出与清空仍位于底部。

学习记录导出为 Excel（.xlsx），含每日统计、学习任务、测试成绩和说明。时长以秒记录，保留各次实际测试成绩；不导出家长密钥或收藏正文。文件在本机生成。

## 1.16 简化学习页
自由学习页面仅显示今日有效时长、复习收藏和学习记录。打开学习区后在前台视频上自动建立计时记录，暂停与后台仍不计观看时间；无手动任务目标要求。七日记录、Excel 导出和清空移入学习记录弹窗。普通闯关入口移除，旧闯关结束但保留成绩；本集限制仅在家长模式开启时显示。跨视频收藏可以复习，自评不虚增当前视频任务成果。

## 1.16.1 家长密码与学习记录
家长自行设置 6–64 位密码，重复输入确认后直接开启，无随机密钥展示步骤。仅保存加盐哈希，旧 9 位密钥仍可用于解除。学习记录弹窗恢复最近七天柱状图，点击日期显示观看、操作和复习时长，保留 Excel 导出。
