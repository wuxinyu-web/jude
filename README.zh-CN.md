# 视频英语学习开发版（哔哩哔哩 / YouTube）

面向高中和大学英语学习者的本地扩展，版本 1.5.0：阅读字幕、收集词句、翻卡自测、打印 Word。全中文界面：字幕、概览、收藏库和学习。保留原有笔记，支持两种视频平台。

## 加载开发版

使用 Chrome 116 或以上版本。在 `chrome://extensions` 开启开发者模式，点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的目录。也可以解压安装包后选择解压目录。不要选择 ZIP 或外层目录，加载后不要移动或删除文件夹。

建议用单独的 Chrome 用户配置测试开发版。原来的日常版及数据保持不变；不同扩展或用户配置不共享存储，需要自己在开发版设置中填写密钥。本扩展存储中已有的 Notes 和 Vocabulary 记录保持原有结构，不按文字长短自动迁移。

修改代码后在扩展管理页重新加载，再刷新视频页面。扩展只使用当前活动的哔哩哔哩或 YouTube 标签页，不借用后台视频。

## 配置密钥

在「设置」填写 DeepSeek 密钥。哔哩哔哩字幕直接从 B 站获取，不需要 Supadata 密钥；使用 YouTube 时才填写 Supadata 密钥。部分 B 站字幕需要先登录。优先选用英文字幕；没有字幕轨时明确提示，不能提取画面内嵌字幕。B 站分 P 分别保存缓存、词句与学习记录。YouTube 的 Supadata 先请求原生字幕；无字幕时，只有点击生成并确认后才请求音频转写。AI 功能沿用 DeepSeek V4 Flash。密钥仅存本地，不要放到聊天、源码或截图里。

官方入口：[Supadata](https://dash.supadata.ai/)、[DeepSeek](https://platform.deepseek.com/api_keys)。服务可能收费，请查看 [Supadata 价格](https://supadata.ai/pricing) 和 [DeepSeek 价格](https://api-docs.deepseek.com/quick_start/pricing)。悬停查词达到 600 毫秒后会调用 AI；相同单词和语境的成功结果在后台内存缓存最多 30 分钟。导出 Word 和翻卡复习不调用 AI。

## 收藏与 Library

- 在 Transcript 英文原文上悬停 600 毫秒，显示音标、语境释义和收藏按钮；点击后才收藏。发音使用本机语音。
- 划选英文字幕后点击「收藏长难句」，支持跨相邻字幕行。先保存原句，再生成中文翻译、句子主干、结构拆解和标签。失败仍保留原句，可在 Library 重试；仍可选择「解释」或「收藏词／短语」。
- 操作范围是 Original 或双语模式中的英文原文，不包括中文字幕和视频画面上的字幕。
- Library 分 Vocabulary、Sentences、Notes。词句支持当前视频／全部、搜索、复习状态筛选、收藏时间升降序和英文 A–Z；当前视频下可按视频出现顺序排列。
- 长难句分别设置语法标签和表达标签，可多选、手动修改、筛选、分组。同一句可出现在多个分组，导出时按 ID 去重。
- 单词和长难句分别上限 500 条，到达上限提示，不自动删除旧收藏。旧单词库里的长句不会被自动重新分类。

## 跟随播放

字幕工具栏提供「回到播放位置」，每次点击读取当前视频时间并定位，暂停时也可用。沉浸模式会自动切换当前台词，交互后可点击「跟上播放」恢复同步。

## 学习任务与复习（1.8.0）

「学习」先显示待开始。范围为当前视频；默认有效时长 20 分钟、单词练习 5 个、句子练习 2 个，词句目标可以设为零。项目尚无片段选择器。顶部固定显示任务状态、累计和剩余时长、练习进度及暂停／继续、结束并总结按钮。

已收集与已练习分开：加入收藏库不会增加练习进度。打开翻卡或查看答案也不算完成；选择「记住了／不熟／没记住」才计入本次练习。同一词句只增加一次目标进度，自评不代表掌握。可以练习当前视频的剩余词句，或复习本次不熟内容。

有效时间为观看、字幕与词句操作、翻卡复习的去重之和。活跃复习优先，其次为有效词句操作，再其次为前台观看。操作和复习在 60 秒无有效交互后停止；普通鼠标移动不算交互。倍速按真实时间计算，后台、窗口失焦、离线、缓冲、拖动及手动暂停不计观看。任务状态与计时原因分开展示，完整说明见「计时规则」。

到达时长目标只提示总结或继续，不强制暂停视频，也不截断后续计时。剩余时间最低为零；只有时长和两类练习目标均达到才显示目标已完成。提前结束展示实际进度和未达标项目。

重新打开学习区、刷新视频、更换视频或浏览器后台服务重启后保留任务并等待手动继续，不补计离开时长。继续时可以绑定当前前台的同一视频，恢复保存的播放位置；不会自动开始播放。结束后也可继续上次学习。减少推荐与评论干扰沿用已有页面控制，退出任务后撤销。

本次总结包含三类时长、练习数／目标数、待复习数量和达标情况；下方显示今日摘要与可点击查看明细的七日柱状图。没有记录时显示引导。学习页和设置均支持导出 JSON 或确认后清空学习记录。数据仅存本机，保留 90 天；清空不会删除词句收藏、笔记及收藏库自评。旧记录保留既有时长和收藏，不推测历史练习成果。

## 下载 Word

在「收藏库」点击「下载 Word」，选择当前筛选结果或勾选项，可合并单词与长难句。各类沿用适用的筛选和排序，生成前显示数量。

- 学习讲义：单词、音标、中文释义、来源例句；长难句、译文、句子主干、拆解和分类。
- 自测版：英文词句和书写留白，答案另起页，题号对应。

输出真实 `.docx`，A4 纵向、黑白、页码，附来源标题、时间点和链接；未完成解析会明确标记。扩展内置 docx 9.6.1 库，本地生成，不上传文档内容，不加载远程脚本。

## 保留的功能与开发验证

Transcript 搜索仍是字面匹配，支持上一个／下一个；阅读位置按当前视频保存在浏览器会话中，最多 20 个视频，会话结束后清除。Overview 和 Notes 保留。已移除 Ask 及联网搜索，启动时清理旧搜索密钥和提问建议缓存，不修改词句收藏。

运行 `npm ci --ignore-scripts` 安装开发依赖，再运行 `npm test`、`npm run check` 和 `npm run package`。浏览器加载不需要构建；运行文件和固定版本的 Word 库已经包含在目录中。`npm run vendor:docx` 从锁定依赖重新生成库副本。

`npm run test:browser` 使用隔离 Chrome 配置和模拟字幕／AI；首次先运行 `npx playwright install chromium --no-shell`。自动化测试不发付费请求。真实视频和服务账户可用性需要另行验证，AI 释义与句法标签也需要学习者判断。
