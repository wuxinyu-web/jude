# 1.5.0 B 站适配与中文界面验收

日期：2026-09-12。开发副本 `youtube-digest-study`，分支 `feature/bilibili-chinese`。扩展名称为「视频英语学习开发版」。日常 YouTube 版未修改；开发版沿用原加载目录与存储结构。

## 改动

- 学习状态每秒累计、侧栏每 500 毫秒读取显示，倒计时显示到秒。仅计入符合条件的前台观看和字幕操作，不把后台、缓冲或离线时间补入。
- 界面、设置、按钮、常规状态提示与导出标题改为中文；英文字幕原文和用户内容保持原样。
- 字幕工具栏新增常驻「跟随播放：开／关」。手动滚动后可点击恢复，立即定位当前已高亮的字幕；修正吸顶工具栏遮挡按钮的问题。
- B 站使用原生字幕接口，优先英文字幕，不需要 Supadata。词句解释、翻译和概览仍使用配置的 AI 服务。
- 支持 BV 视频及带 bvid 的列表播放页，保留分 P 身份和来源链接；分 P 切换与换视频一样处理学习会话。保留 YouTube 支持。
- B 站没有可读取字幕轨时明确提示；不对内嵌画面字幕做 OCR，不提供无字幕音频转写。本版没有适配番剧 ep 播放页。

## 自动化检查

`npm test` 通过 188 项测试；`npm run check` 和 `npm run package` 通过，发布包含 38 项白名单运行文件。新增覆盖 B 站 WBI 签名、字幕接口、英文轨优先、登录失败、来源地址限制、分 P 标识及 Word 来源链接。

浏览器集成测试使用独立的临时 Chrome 配置、真实扩展侧栏及 HTMLVideoElement。YouTube 和 B 站分别运行：秒级倒计时、跟随按钮重新定位、中文设置无 Supadata 保存、悬停缓存与过期请求、双语跨行选择、分类、前台／后台计时、到时暂停、加时、Word 下载、复习与退出清理。字幕接口和 AI 数据为测试夹具，不调用付费服务。B 站测试完整经过原生字幕适配器，并另以解压后的发布包运行。

## 真实 B 站验证

使用独立、未登录的 Chrome 配置访问 https://www.bilibili.com/video/BV1FU4y1F7Px/ 。确认真实网页、视频元素和「英语学习」按钮存在。实际调用原生字幕接口得到需要登录的响应，扩展返回中文提示「请先在当前 Chrome 用户配置登录哔哩哔哩，再重新获取字幕」。

没有复制日常 Chrome 登录数据或 API Key。登录后的真实字幕提取、DeepSeek 翻译／解析完整流程仍需在用户自己的配置中验收；模拟浏览器成功不代表这项账户环境联调已完成。

Word 排版沿用 1.4.0 已渲染检查的模板（详见 STUDY-VALIDATION.md）。本次验证真实 DOCX 下载、文件结构和 B 站来源链接，没有再次声明逐页 Word／WPS 打印渲染验收。
