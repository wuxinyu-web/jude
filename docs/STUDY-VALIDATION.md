# Study 开发版验收记录

日期：2026-09-12。独立副本 `youtube-digest-study`，功能分支 `feature/study-library`，版本 1.4.0。日常版 `youtube-digest` 未修改。

## 自动化验证

- `npm test`：151 项测试，包括原有字幕、翻译、Notes、Vocabulary、安全和异步状态回归。
- `npm run check`：运行资源语法、Manifest 引用、32 项打包白名单、凭据扫描与测试。
- `npm run package`：生成真实可解压加载的扩展 ZIP，包含本地 docx 库和全部提示词。
- 新增模型与服务测试覆盖词条分词、语境缓存、并发和失败重试；原句先持久保存、500 条独立容量、删除与手动分类在异步解析中保持有效；筛选排序和分组去重；旧单词保持原有数据；零目标、真实经过时间、缓冲／拖动、失焦、跨视频／标签页、心跳间断、休眠／重启、午夜切分和复习状态。
- `npm run test:browser` 使用隔离 Chrome 配置、真实扩展 Service Worker、原生侧栏和 HTMLVideoElement。字幕与 AI 响应是测试数据，绝不调用付费服务。
- 浏览器测试覆盖 600 毫秒悬停、快速移开取消、过期结果不覆盖新词、缓存收藏、双语跨行英文提取、分类修改、播放与后台计时、到时暂停、加时、实际 DOCX 下载、翻卡自评及退出后撤销页面改动。

## Word 样例

用生产导出模块生成学习讲义和自测版，含中英文、音标、长句、多标签和未完成解析条目。使用本机 LibreOffice 打开并转换，再逐页检查：讲义 2 页、自测 4 页，中文可见、A4 黑白、题号对应、来源链接和页码正常，参考答案在第 3 页另起页，无裁切。

渲染环境需要安装中文字体；本机使用 Songti SC，并显式将 macOS 字体目录交给测试渲染器。扩展导出的文件包含中文字体现有名称，不上传或打包系统字体。

## 真实网站验证与剩余人工验收

在独立浏览器访问 Stanford 的 Steve Jobs 2005 演讲视频（https://www.youtube.com/watch?v=UF8uR6Z6KLc），已确认真实页面加载、Digest 按钮注入、播放器与字幕控件存在。YouTube 在这个隔离环境要求登录验证，未绕过该限制。

本次没有将日常浏览器登录资料或 API Key 复制到测试配置，也没有发出真实 Supadata／DeepSeek 请求。因此以下属于待完成的账户环境验收，不能用模拟测试代替：

1. 在独立 Chrome 用户配置登录 YouTube，填写自己的 Supadata 和 DeepSeek 密钥。
2. 打开可播放且有英文字幕的视频，检查原文与双语字幕、悬停真实词义、划选后的中文结构解析。
3. 开始学习，确认真实播放器到时暂停；复习本次收藏并下载讲义／自测版。
4. 用学生实际使用的 Word 或 WPS 打开下载文件并检查打印预览。
